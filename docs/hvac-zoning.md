# Room-by-room heating and cooling (zoning)

One furnace/AC and one Nest, but every room aims for its own temperature.
Home Assistant reads a sensor in each room, decides when to heat or cool,
nudges the Nest to make it happen, and uses the smart vents
([ben-hawks/yet-another-smart-vent](https://github.com/ben-hawks/yet-another-smart-vent))
to send the air where it's needed.

Everything is generated by `tools/hvac_zones.py`. Edit the `ROOMS` list
there and run `python3 tools/hvac_zones.py`.

## Who's in control

**Climate → Zones → Controlled by** has three settings:

| Setting | What happens |
|---|---|
| **Nest** (default) | Home Assistant changes nothing. The Nest runs on its own schedule, as before. |
| **Preview** | Home Assistant works out what it *would* do every minute and writes it to the logbook, e.g. *"would call heat (was idle); Nest {'target_temp_low': 73, …}; vents cover.vent_living_1 → 20%"*. Nothing is sent to the Nest or the vents. Use this while sensors and vents are going in. |
| **Home Assistant** | Home Assistant drives the Nest and the vents. |

Switching away from **Home Assistant** opens every vent and sets the Nest
back to the house mode's hallway targets. The Nest's own schedule takes over
again at its next scheduled change.

## How it decides

- **Targets:** each house mode (Home / Sleep / Away) has a heat and a cool
  setpoint. Each room adds its own offset, plus an extra one that applies
  only in Sleep. With **Auto house mode** on, the mode switches to Sleep at
  bedtime, to Home at wake-up, and to Away when nobody has been home for
  15 minutes.
- **Season:** the Nest's own mode still picks it. *Heat* only heats, *Cool*
  only cools, *Heat-Cool* does whichever the rooms need, and *Off* does
  nothing.
- **Starting:** a call starts when any zoned room is 0.5 °F past its target.
- **Stopping:** a call stops when every zoned room is 0.5 °F past it, or when
  the rooms average 2 °F past target (so one stubborn room can't overheat
  the rest).
- **Timing:** each call runs at least 5 minutes, and there are at least
  5 minutes between calls.
- **Driving the Nest:** to heat, Home Assistant sets the Nest 2 °F above the
  hallway's reading; to cool, 2 °F below it; when idle, the other way. It
  only sends a change when the Nest would otherwise do the wrong thing.
- **Backstop:** while idle, the Nest is never set below the **Away heat**
  setpoint or above the **Away cool** setpoint. If Home Assistant goes down,
  the Nest still keeps the house at Away temperatures.
- **Vents:** during a call, each room's vents are set by how far the room is
  from its target:

  | Room is… | Vent position |
  |---|---|
  | still short of target | 100% |
  | up to 1 °F past target | 50% |
  | further past target | Vent minimum position (default 20%) |

  Rooms marked **left out of zoning** go to the minimum. Rooms with no
  reading stay open. Vents don't move between calls, which saves their
  batteries.
- **Airflow floor:** at least **Minimum open registers** (default 60%) of
  all supply registers stay open. Plain registers count as open, and the
  neediest rooms are opened first to reach the floor. This keeps static
  pressure, and so the furnace's temperature rise, in check. The Ameristar
  M801P080BU36 is rated for a 30–60 °F rise and is already near the top of
  that range on its medium-low fan speed.
- **Delta Tango:** if `RISE_SENSOR` is set and the supply/return rise passes
  **Max temperature rise** (default 57 °F), every vent opens for 30 minutes.

## Adding a room's sensor and vents

IKEA TIMMERFLOTTE sensors are Matter-over-Thread devices. Add them with
**Settings → Devices & services → Add device → Matter**. They join the same
Thread network as the vents. Then, in `tools/hvac_zones.py`:

```python
{"id": "bedroom", "name": "Bedroom",
 "sensor": "sensor.bedroom_timmerflotte_temperature",   # the room's sensor
 "vents": ["cover.bedroom_smart_vent_vent"],             # smart vents in the room
 "registers": 0},                                        # plain registers left
```

Run `python3 tools/hvac_zones.py`, reload the YAML (**Developer Tools → YAML
→ All YAML configuration**), and the room shows up under **Zones**.

`registers` should count every supply register in the house, smart or not.
Those counts are what the airflow floor is based on, so it pays to get them
right.

## First run checklist

1. Leave **Controlled by** on **Nest** and check that each room shows a
   temperature and a sensible status.
2. Switch to **Preview** for a few days and read the logbook entries for
   **Zoning call**. Do the decisions make sense?
3. Switch to **Home Assistant** while someone is home to watch the first
   few cycles.

# Pop-ups and corner badges on the TVs (TvOverlay)

[TvOverlay](https://github.com/gugutab/TvOverlay) shows pop-ups and small
corner badges over whatever is playing. It's free on the Play Store (the paid
"Premium" is only for its phone remote app, which this setup doesn't use).
Home Assistant talks to each TV directly on port 5001
(`packages/tv_overlay.yaml`, generated by `tools/tvoverlay.py`).

What you get:

| | |
|---|---|
| Pop-ups | Doorbell (with the camera's picture), a new household alert (the Home tab's red banner), laundry done, hens too hot or too cold |
| Corner badges | Outside temperature, alerts, laundry waiting to be emptied, coop comfort |
| Watchdog | When a TV turns on after being off for 5+ minutes, the badges are sent again, and TvOverlay is started if it isn't running, but only while the TV is on its home screen (it never opens over an app you're watching) |

Only TVs that are on get anything.

## 1. Install on each TV

On the TV: **Play Store → search "TvOverlay" → Install**. Or open its store
page from Home Assistant: **Developer Tools → Actions**, YAML mode:

```yaml
action: androidtv.adb_command
target:
  entity_id:
    - media_player.living_room_main_room_tv_adb
    - media_player.bedroom_bedroom_tv_adb
    - media_player.game_room_game_room_tv_adb
data:
  command: am start -a android.intent.action.VIEW -d market://details?id=com.tabdeveloper.tvoverlay
```

## 2. Permissions, then start it once

Google TV has no on-screen switch for "draw over other apps", and closes
background apps to save power; both are fixed with ADB. One action for all
three TVs:

```yaml
action: androidtv.adb_command
target:
  entity_id:
    - media_player.living_room_main_room_tv_adb
    - media_player.bedroom_bedroom_tv_adb
    - media_player.game_room_game_room_tv_adb
data:
  command: >-
    appops set com.tabdeveloper.tvoverlay SYSTEM_ALERT_WINDOW allow;
    dumpsys deviceidle whitelist +com.tabdeveloper.tvoverlay;
    monkey -p com.tabdeveloper.tvoverlay -c android.intent.category.LEANBACK_LAUNCHER 1;
    sleep 4; input keyevent KEYCODE_HOME
```

TvOverlay opens briefly and the TV goes back to its home screen.

## 3. Find each TV's IP address

```yaml
action: androidtv.adb_command
target:
  entity_id: media_player.living_room_main_room_tv_adb
data:
  command: ip -4 -o addr show | grep -v ' lo '
```

The answer is in that entity's **adb_response** attribute (**Developer Tools →
States**), e.g. `... inet 192.168.1.42/24 ...`: the IP is `192.168.1.42`.
Repeat for `media_player.bedroom_bedroom_tv_adb` and
`media_player.game_room_game_room_tv_adb`.

These are only a fallback: each time it sends, Home Assistant looks up the
TV's current IP from a device tracker (e.g. UniFi Network's) on the same
device as the TV's Android TV Remote or ADB entity, so a new DHCP address
doesn't break anything (`TV_REMOTES` in `tools/tvoverlay.py`).

## 4. Settings

In `tools/tvoverlay.py`, fill in `TV_IPS`, `HA_URL` (Home Assistant's address
as the TVs reach it) and, for the doorbell, `DOORBELL_TRIGGER` and
`DOORBELL_CAMERA`; run `python3 tools/tvoverlay.py`. The doorbell pop-up
loads the camera's picture through its own link, which carries a short-lived
access token, so no snapshot is saved anywhere.

Then **Developer Tools → YAML → All YAML configuration** (new `rest_command`s
need a restart the first time).

## 5. Test

```yaml
action: script.tv_popup
data:
  title: Hello from Home Assistant
  message: TvOverlay is working
  small_icon: mdi:home-assistant
  seconds: 10
```

and `script.tv_badges` to put the corner badges up.

## Sending your own

`script.tv_popup` takes `title`, `message`, `small_icon` / `large_icon`
(`mdi:` icons or image URLs), `image` (a picture URL the TVs can reach),
`color`, `seconds`, `corner` (`bottom_start`, `bottom_end`, `top_start`,
`top_end`) and `id`. To add a badge, add it to `badges_script()` in
`tools/tvoverlay.py`.
